 3. Протоколы взаимодействия между модулями

 Протокол 1: Вызов сервиса вычислений (CalculatorService)
Участники: ViewModels -> Services
Назначение: Выполнение базовых арифметических операций.
Интерфейс: double Calculate(double first, double second, string op)
Формат данных: Типы C# (double для операндов и результата, string для знака операции `+`, `-`, `*`, `/`).
Соглашения: Метод синхронный, при делении на ноль возвращает `0`.

 Протокол 2: Связывание данных 
Участники: Views -> ViewModels
Назначение: Передача вводимых пользователем данных и команд управления в модель представления.
Формат данных: Свойства и команды C# 

4. Соглашения об именовании и версионировании
1. Правила именования:**
   Классы, сервисы, методы — `PascalCase` (`CalculatorService`, `Calculate`).
   Пространства имён совпадают со структурой папок (`SimpleCalculator.Services`, `SimpleCalculator.Views`).
2. Версионирование (SemVer):**
   Формат версии: `MAJOR.MINOR.PATCH` (Текущая версия проекта: `1.0.0`).

5. Заключение
Все производные файлы сборки (`bin/`, `obj/`) корректно исключены через `.gitignore`. Документированная структура позволяет проводить изолированную разработку и интеграцию модулей.
