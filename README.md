\# Проект SimpleCalculator (Лабораторная работа №1)



Приложение «Калькулятор» на WPF, отрефакторенное в рамках ЛР №1.



\## Структура проекта

\* `Views/` — компоненты пользовательского интерфейса.

\* `Services/` — сервисы бизнес-логики и вычислений.

\* `ViewModels/` — слой связи UI и логики.
